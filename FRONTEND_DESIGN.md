## 🎯 Дизайн Принципы

### Цветовая Палитра
```
Primary: #fb923c (Оранжевый)
Secondary: #f97316 (Тёмный оранжевый)
Background: #fff7ed → #fafaf9 (Gradient)
Success: #10b981 (Зелёный)
Warning: #f59e0b (Жёлтый)
Error: #ef4444 (Красный)
Info: #3b82f6 (Синий)
```

### Типография
- **Font**: System font (-apple-system, BlinkMacSystemFont)
- **Weights**: 400, 500, 600, 700, 900
- **Sizes**: 12px, 14px, 16px, 18px, 20px, 30px

### Компоненты
- **Cards**: `rounded-2xl border border-orange-100 shadow-sm hover:shadow-md`
- **Buttons**: Градиент или мягкий фон с transitions
- **Inputs**: Оранжевая обводка при focus
- **Badges**: Border + soft background + strong text

### Layout
- **Sidebar**: 256px fixed, gradient background
- **Main**: flex-1, p-8
- **Grids**: responsive (1 → 2 → 4 колонки)

## 🚀 Как Использовать

### Установка
```bash
cd admin-panel
npm install
npm run dev
```

### Build
```bash
npm run build
```

### Развёртывание
```bash
# На Vercel
vercel

# Или на Netlify
netlify deploy --prod --dir=dist
```

## ✨ Особенности

1. **Микро-интеракции**
   - Кнопки масштабируются при клике (scale-95)
   - Карточки меняют тень при наведении
   - Input поля поднимаются вверх при focus

2. **Плавные переходы**
   - Все элементы переходят в течение 200ms
   - Custom scroll поведение
   - Smooth page transitions

3. **Бренд-идентичность**
   - Каждый элемент отражает ценности КОРИЦА FAMILY
   - Уютный, дружелюбный интерфейс
   - Профессиональный и современный дизайн

4. **Доступность**
   - Хорошая контрастность текста
   - Достаточные размеры для touch-устройств
   - Семантическая HTML структура
