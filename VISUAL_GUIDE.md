## Анимации и Интеракции

### Hover на карточке
```
Before:  ┌─────────────────┐
         │ shadow-sm       │
         │ border-orange   │
         └─────────────────┘

After:   ┌─────────────────┐
    ↓    │ shadow-md ↑     │
         │ border-orange   │
         └─────────────────┘
```

### Клик на кнопку
```
Before:  [button at 100% size]

Click:   [button at 95% size] ← scale-95
         [shadow increases]

After:   [button back to 100%]
         [fast transition 200ms]
```

### Focus на input
```
Before:  ┌───────────┐
         │ gray-200  │
         └───────────┘

After:   ┌───────────┐
    ↓    │ orange-400│  ← ring-2
         └───────────┘
```

## Spacing и Layout

### Padding
```
p-4  = 16px   (компактный)
p-5  = 20px   (стандартный)
p-6  = 24px   (просторный)
p-8  = 32px   (очень просторный)
```

### Gaps между элементами
```
gap-2 = 8px   (тесно)
gap-3 = 12px  (удобно)
gap-4 = 16px  (просторно)
gap-6 = 24px  (очень просторно)
```

### Border Radius
```
rounded-lg   = 8px   (немного)
rounded-xl   = 12px  (нормально)
rounded-2xl  = 16px  (мягко, как карточки)
```
