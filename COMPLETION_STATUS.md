## 🎓 Как Использовать

### Локальная разработка
```bash
cd admin-panel
npm install
npm run dev
# Открыть http://localhost:5173
```

### Production сборка
```bash
cd admin-panel
npm run build
# dist/ готов к деплою
```

### Деплой на Vercel
```bash
cd admin-panel
vercel deploy --prod
```

### Деплой на Netlify
```bash
cd admin-panel
netlify deploy --prod --dir=dist
```
