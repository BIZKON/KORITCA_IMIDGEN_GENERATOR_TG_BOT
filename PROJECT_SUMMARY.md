# 📊 Резюме Проекта ИМИДЖЕН

## 🎯 Объемность проекта

**ИМИДЖЕН** — полнофункциональная система управления контентом с автоматизацией через AI.

```
┌─────────────────────────────────────────────────┐
│  ИМИДЖЕН: Генератор Контента                    │

│                                                 │
│  Frontend:          React SPA (Vite)            │
│  Backend:           Supabase Edge Functions     │
│  Database:          PostgreSQL (Supabase)       │
│  APIs:              AtlasCloud (Gemini, Imagen)│
│  Bot:               Telegram (Webhook)          │
│  Style:             Tailwind CSS                │
│  Type Safety:       TypeScript                  │
└─────────────────────────────────────────────────┘
```
